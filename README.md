# ポケモン図鑑

PokeAPIを使用したインタラクティブなポケモン図鑑Webアプリケーションです。

## 機能

### 基本機能
- **ポケモン一覧表示**: 最初の20匹のポケモンを美しいカードスタイルで表示
- **追加読み込み**: 「もっと読み込む」ボタンで追加のポケモンを読み込み
- **レスポンシブデザイン**: デスクトップ、タブレット、スマートフォンに対応

### 検索機能
- **名前検索**: ポケモンの英語名や日本語名で検索
- **番号検索**: ポケモンの図鑑番号で検索
- **リアルタイム検索**: Enterキーまたは検索ボタンで即座に検索

### フィルタリング機能
- **タイプ別フィルター**: 18種類のポケモンタイプで絞り込み
- **複合タイプ対応**: 複数のタイプを持つポケモンも適切に表示

### 詳細表示
- **詳細モーダル**: ポケモンをクリックすると詳細情報をモーダルで表示
- **基本情報**: 名前、図鑑番号、タイプ、高さ、重さ
- **ステータス**: HP、攻撃、防御、特攻、特防、素早さをバー形式で表示
- **説明文**: ポケモンの公式説明文（日本語）
- **高品質画像**: 公式アートワークを優先表示

## 技術スタック

- **HTML5**: セマンティックなマークアップ
- **CSS3**: 
  - Flexbox & CSS Grid レイアウト
  - グラデーション背景
  - アニメーション効果
  - レスポンシブデザイン
- **JavaScript (ES6+)**:
  - Fetch API for HTTP requests
  - Async/Await パターン
  - DOM manipulation
  - Event handling
- **PokeAPI**: https://pokeapi.co/ からのデータ取得

## 使用方法

1. **起動方法**:
   - Webサーバーでホストするか、`index.html`をブラウザで直接開く
   - モダンブラウザ（Chrome、Firefox、Safari、Edge）推奨

2. **操作方法**:
   - **閲覧**: ページを開くと自動的に最初の20匹のポケモンが表示
   - **検索**: 上部の検索バーにポケモン名または番号を入力
   - **フィルター**: タイプ選択ドロップダウンで絞り込み
   - **詳細表示**: ポケモンカードをクリックで詳細モーダル表示
   - **追加読み込み**: 「もっと読み込む」ボタンで更多ポケモンを表示

## 機能詳細

### 検索機能
- **英語名検索**: 例）`pikachu`, `charizard`
- **日本語名検索**: 例）`ピカチュウ`, `リザードン`（一部対応）
- **番号検索**: 例）`1`, `25`, `150`

### タイプフィルター
サポートされているタイプ：
- ノーマル、ほのお、みず、でんき
- くさ、こおり、かくとう、どく
- じめん、ひこう、エスパー、むし
- いわ、ゴースト、ドラゴン、あく
- はがね、フェアリー

### ステータス表示
各ポケモンの基本ステータスを視覚的なバーで表示：
- HP (Hit Points)
- こうげき (Attack)
- ぼうぎょ (Defense)
- とくこう (Special Attack)
- とくぼう (Special Defense)
- すばやさ (Speed)

## APIについて

このアプリケーションは [PokeAPI](https://pokeapi.co/) を使用しています。
- 完全無料のRESTful API
- レート制限あり（適切な使用を推奨）
- リアルタイムデータ取得
